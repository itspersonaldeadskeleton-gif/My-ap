# FitMind

AI personal stylist Flutter app.

## Setup

1. Install Flutter SDK (>=3.22).
2. Run `flutter pub get`.
3. Copy `.env.example` to `.env` and fill keys (optional).
4. Run `flutter run`.

## Optional integrations

- Supabase: set SUPABASE_URL and SUPABASE_ANON_KEY.
- Weather: set WEATHER_API_KEY (backend).
- AI: set AI_API_KEY (backend).

App runs fully offline in guest mode without keys.
